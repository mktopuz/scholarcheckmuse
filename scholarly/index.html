Rules catch measurable formatting. An AI review can flag things rules cannot — inconsistent heading capitalization, a missing abstract, caption wording that drifts. It is off until you add your own API key below.

AI settings — your key stays on this device

The key is kept in this browser's local storage only — never in the document, never on a server of ours (there is none). When you run an AI review, text excerpts from your document (headings, front matter, samples) are sent to the provider at the base URL above. Rule checks never send anything.

What is checked

  • Page size and margins — read from every section of the document and compared with the guideline values, with a small tolerance so Word rounding does not raise false alarms.
  • Line spacing — resolved the way Word resolves it: paragraph setting, then style, then document defaults.
  • Body font and size — weighted by how much text actually uses each font. Table text is reported separately, because most guides allow smaller type in tables.
  • Heading structure — whether chapter and section titles really use Heading 1/2/3 styles. Bold text alone is not a heading, and without styles Word cannot build an automatic table of contents.
  • Page numbers — whether a page-number field exists in a header or footer, and where it sits.
  • Required parts — the front-matter sections your document type requires (abstract, table of contents, references, and similar).

What it cannot do — honestly

  • It cannot name the page a problem is on: a .docx does not store page breaks. The report gives the section, the paragraph number, and the first words of the paragraph instead.
  • It does not judge content, argument, or citation style, and it never modifies your file.
  • Built-in guideline values are starting points, not gospel. Guides are revised every few years — if yours differs, use Custom rules with the exact values from your current guide.
